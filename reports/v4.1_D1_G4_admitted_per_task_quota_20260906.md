# v4.1 D1 B 侧：G4 admitted per-task 单源口径 + t2ranking 降采样/分层方案 — 2026-09-06

> 作者：DGXD01（Data-B）| 依据：Data-R 终裁 B1（t2ranking 43% → 按 admitted per-task 单源 ≤25% 降采样/分层）+ P04 配额
> 状态：方案文档（待 Data-R 批准执行 / 或接受豁免申请）

## 一、G4 口径定义（Data-R B1 定稿）
- **分母 = admitted Retrieval Gold**（非 legacy IN_SCOPE 465、非候选池总量）；
- **单源 ≤25%**：任一 dataset 来源在 admitted Retrieval Gold 中占比 ≤25%；
- Retrieval Query 正式目标 = **175**（v4.1 表 6）→ **t2ranking 上限 = 175 × 25% = 43.75 → ≤43 条**。

## 二、现状与缺口
| 来源 | legacy 可复用候选 | 说明 |
| --- | --- | --- |
| t2ranking（public_derived） | 200（Data-R A3 已批准为可复用候选） | 若全量进入 admitted Retrieval Gold（175），占 200/175>100%，远超 25% |
| gold 真查询（team_authored） | 5（Data-R A3：60 gold = 5 真查询 + 55 复制） | 55 复制 M1-KB 后族内留 1 DROP，不计可复用 |

- **若 admitted Retrieval Gold = 175**：t2ranking 最多 **43 条** → 200 需降采样 **157 条**；
- 缺口补足：剩余 132（175-43）由 gold 5 + OS/改写变体等补齐（受 M1-KB / P04 配额约束）。

## 三、方案（二选一，请 Data-R 定）
**方案 A（推荐）：t2ranking 降采样/分层至 ≤43**
- 从 200 条 t2ranking 按 query 覆盖分层抽取 ≤43 条代表性检索单元（保证 source 多样、query 类型均衡、不集中单一模板族）；
- 保证 provenance/license 通过（已 OK）；D4 diversity 达标；剩余 157 不进入 Retrieval Gold（可留作 dev/reg 候选或弃用）；
- 需 P30 Admission 前重跑 dedup/leakage 定稿（Data-R B1 要求）。

**方案 B：显式豁免申请**
- 若 t2ranking 200 全量作为 Retrieval Gold 对评测有特殊价值（如 175 目标主要依赖 t2ranking），由 B 提交豁免申请 + 理由（单一来源集中风险、模板族 25% 冲突），Data-R 显式批准后执行；
- 豁免须同时满足 G4 template≤25%（族级）与 source 分级要求，否则不予豁免。

## 四、执行顺序（选定后）
1. 选定 A/B → P30 Admission 前重跑 dedup/leakage → 更新 audit/summary（template 集中度按 admitted 口径复算）；
2. t2ranking 分层抽样（方案 A）或豁免记录（方案 B）；
3. 产出 admitted Retrieval 候选清单 → 供 P30 G1-G5 + fresh40 抽样。
