# v4.1 G2 scope 人工复核标准（Data-A）

- 角色：Data-A（lyf-1213）
- 版本：v4.1（Rev2，按 Data-R review 2026-09-05 修正判定顺序）
- 依据：KMA Canonical 5.8 `preference_scope ∈ {global, topic, tool, session, time_window}`；v4.1 台账 10_任务判定矩阵 / 11_Admission G2（人工 100% 确认）；v4 gap_fix_plan G2。
- 目的：进入正式 Gold 的 Preference 候选，逐条人工复核。**先判是不是 Preference，再判 scope**；scope 不能把 non-preference 重新"合法化"。

## 一、判定顺序（对每条候选，严格三步）

### 第 1 步：G2 Task Semantic —— 先判定样本本身属于哪一类
按 v4.1 任务判定矩阵 / P10 语义，判断表达属于：
- `persistent_preference`（长期偏好）
- `temporary_preference`（临时偏好，有明确时效）
- `task_constraint`（仅本次任务的约束）
- `ordinary_request`（普通问答/一次性请求）
- `non_preference`（非偏好，例如普通陈述、命令、不可存储内容）

**一次性/时效类表达的口径（确定规则，不用多口径）**：
- 单次请求约束（"这次就按英文回复"且无跨会话持续语义）→ `task_constraint`
- 明确整个会话持续（"本次会话都用英文"）→ `temporary_preference` + scope=`session`
- 明确时间区间（"项目期间用英文"）→ `temporary_preference` + scope=`time_window`

判定优先于 scope。**仅当样本被判定为 preference（persistent/temporary/implicit）时才进入第 2 步赋 scope。**

### 第 2 步：Preference eligibility / class —— 仅对合法 preference 判类
- `explicit persistent`（显式、无歧义、长期）→ 可赋 scope
- `implicit repeated behavior`（多次一致行为推断）→ 需证据，低置信 `NEEDS_REVIEW`
- `temporary`（有时间窗）→ 可赋 scope（含 time_window）
- `sensitive / non-storable` → 判 negative / blocked by policy，**不赋 scope 不入库**

### 第 3 步：Preference scope —— 仅对可入库偏好赋 scope
- 针对**某个具体应用/工具**的行为（项目管理工具、邮件客户端）→ `tool`
- 针对**某类工作主题**（周报、代码评审、装修）→ `topic`
- **整体系统/默认行为**（以后都先问我确认）→ `global`
- **本次会话/本次请求** → `session`
- **某时间窗**（本月、项目期间）→ `time_window`
- 无法仅凭文本确定对象 → `NEEDS_REVIEW`，不猜。

## 二、禁止项

- 不得机械默认 `tool`（旧映射"周报→tool"已废弃）。
- app≠tool、task≠topic 必须按语义裁决，不得直接套用旧 scope 名。
- 不得用 `active/v1` 等默认业务真值补 Schema。
- **不得把 non-preference / task_constraint / ordinary_request 当成合法 Preference 赋 scope。**
- 敏感/不可存储偏好：判定 negative / blocked by policy，不判 scope 后入库。

## 三、scope 判定速查（供 A 标注时对照）

| 用户表达 | 第1步判定 | scope（第3步） |
| --- | --- | --- |
| 以后每周报告都用要点 | persistent_preference | topic（针对报告主题） |
| 这个项目管理工具里用中文标签 | persistent_preference | tool（针对具体工具） |
| 以后都先问我确认 | persistent_preference | global（整体默认） |
| 这次就按英文回复（单次请求） | task_constraint | **不赋 scope**（非合法 preference） |
| 本次会话都用英文 | temporary_preference | session |
| 项目期间用英文回复 | temporary_preference | time_window（有明确时间窗） |
| 发邮件时默认带签名 X | persistent_preference | tool（邮件客户端行为） |
| 做周报时用简洁要点 | persistent_preference | topic |
| 某个具体工具 vs 助手整体 | persistent_preference | 工具唯一确定→tool；助手整体→global 或 NEEDS_REVIEW |
